# Worms Web

브라우저에서 하는 웜즈 스타일 턴제 포격 게임입니다. 빌드나 서버 없이 정적 파일로 동작합니다.

## 모드

| 모드 | 설명 |
|---|---|
| AI 대전 | 나 + AI 1~3팀, 난이도 쉬움/보통/어려움 |
| 한 PC 대전 | 2~4팀이 키보드 하나로 번갈아 플레이 |
| 온라인 | 방장이 방 만들기 → 6자리 코드 공유 → 최대 4인 실시간 대전 (WebRTC P2P) |

## 조작

- `←` `→` 이동, `↑` `↓` 조준, `Enter` 점프
- `Space` 누르고 있다가 떼면 발사 (오래 누를수록 강하게)
- `1` 바주카 (바람 영향) · `2` 수류탄 (3초 후 폭발, 튕김) · `3` 샷건 (직선)
- 발사 후 4초 동안 이동해서 피할 수 있음. 물에 빠지면 즉사

## 구조

```
index.html        화면 + CSP
style.css
game.js           지형·물리·무기·AI·네트워크·렌더 전부
vendor/peerjs.min.js   PeerJS 1.5.4 (저장소에 직접 포함, 외부 CDN 미사용)
```

## 온라인 구조

- 방장 브라우저가 물리 계산과 판정을 모두 맡음 (host-authoritative)
- 참가자는 키 입력만 보내고, 방장이 보내는 상태(초당 20회)와 폭발 이벤트로 화면을 그림
- 지형은 방장이 보낸 seed로 생성하고, 폭발 이벤트를 받을 때마다 깎음
- 시그널링(연결 중개)만 PeerJS 공용 서버(`0.peerjs.com`)를 쓰고, 게임 데이터는 브라우저끼리 직접(P2P, DTLS 암호화) 주고받음

## 보안

| 항목 | 조치 |
|---|---|
| 스크립트 주입 | CSP `script-src 'self'`, 인라인·외부 스크립트 차단. 닉네임은 `textContent`/`fillText`로만 출력 |
| 외부 통신 | CSP `connect-src`는 PeerJS 시그널링 서버만 허용 |
| 공급망 | PeerJS를 고정 버전으로 저장소에 포함 (SHA-256 `ad5d8870…6fe5`) |
| 방 접근 | 방 코드는 `crypto.getRandomValues`로 만든 6자리 (31^6 ≈ 8.9억 가지), 시작 후 입장 불가, 최대 4명 |
| 부정 입력 | 방장이 모든 입력 검증: JSON 직렬화만 허용, 메시지 512B 제한, 초당 60개 제한, 5초 안에 인사(`hi`)가 없으면 연결 종료, 현재 차례 팀의 입력만 반영 |
| 방장 데이터 | 참가자도 방장이 보낸 상태를 형식·범위 검증 후 사용 |
| 개인정보 | 저장하는 것은 닉네임(브라우저 localStorage)뿐. 서버 저장 없음 |

### 한계 (알고 쓰기)

- P2P 특성상 같은 방 사람끼리는 서로의 IP 주소를 알 수 있음 → 모르는 사람과 방 코드를 공유하지 말 것
- 방장이 모든 판정을 하므로 방장은 콘솔로 조작이 가능함 (친구끼리 하는 게임 기준)
- 회사망처럼 WebSocket/WebRTC를 막는 네트워크에서는 온라인 모드가 동작하지 않음 → 집이나 모바일 핫스팟에서 이용
- 방장 탭이 백그라운드로 가면 브라우저가 계산을 멈춤 → 방장은 게임 창을 띄워 둘 것

## 로컬 실행

```
python -m http.server 8000
```
→ http://localhost:8000 (파일을 더블클릭해서 열면 일부 브라우저에서 동작하지 않음)
